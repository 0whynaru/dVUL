## Installation
This tool can only work on Linux if u want use command only.
```bash
git clone https://github.com/0whynaru/dVUL.git
cd dVUL
chmod +x setup.sh
sudo ./setup.sh
```
## 🚀 Usage

```bash
python dvul.py -sx "https://target.com/page?param=value"
```
